# Orderflow Wall v2.0.0-beta.2 — public testing build

Windows 11 x64 portable ZIP. Extract the full folder and run OrderflowWall.exe. Keep _internal beside the executable. Open-Studio.cmd opens the synthetic-data rule editor prototype.

No trading API keys or order execution. Live public market data requires Internet. No macOS or mobile installer is available.

This is a DEV-policy Beta for testing, not a paid commercial release. The EXE does not support automatic updates and is not publisher-code-signed. Studio uses synthetic market data. CME integration and clean-machine/mobile acceptance are not verified.

Validation: backend 447 + Studio 3 tests; frontend 95 tests; Windows EXE startup smoke checks. This is not a 24-hour stability certification.
